# 집알림

서울과 출퇴근 가능한 수도권의 공공임대 모집공고를 모아, **내가 지원할 수 있는 공고와 실제로 살고 싶은 주택**을 빠르게 골라내는 개인용 도구입니다.

목표는 공고를 구경하는 것이 아니라 **당첨될 때까지 새 공고를 놓치지 않고 반복해서 지원하는 것**입니다.

## 왜 만들었나

LH·SH 공고는 직접 찾아 들어가 공고문과 첨부파일을 읽어야 합니다. 공고 하나에 여러 지역과 여러 주택이 섞여 있어, 정작 내가 지원하고 싶은 주택을 찾는 데 시간이 걸립니다.

행정구역만으로는 판단하기도 어렵습니다. 서울 안에서도 생활 거점까지 한참 걸리는 곳이 있고, 경기도라도 더 가까운 곳이 있습니다. 이직이나 회사 이전으로 생활 거점이 바뀔 수도 있으니 특정 지역을 고정 기준으로 두지 않습니다.

집알림은 이 과정을 대신 정리해, **지원할 가치가 있는 공고와 주택부터** 보여줍니다.

## 흐름

```text
새 공고 발견 → 지원 가능 여부 → 실제 공급주택 → 생활권·출퇴근 → 과거 경쟁률
→ 우선 확인 대상 → 알림 → 지원 준비 → 결과 기록 → 다음 공고
```

## 무엇이 다른가

같은 문제를 다루는 서비스를 조사한 결과, **공식·비공식을 통틀어 `지역 + 유형` 필터에서 멈춥니다.** 자격을 판정하는 곳은 없고, 주택 단위 정보를 가진 곳은 사람이 PDF에서 손으로 옮긴 사이트뿐입니다.

전국을 덮으려다 깊이를 잃는 대신, 이 도구는 **1인·서울 생활권으로 범위를 좁히고 깊이로 갑니다** — 주택 단위 분석, 출퇴근 판단, 경쟁률 이력, 지원 이력.

조사 원본은 [PRODUCT](docs/PRODUCT.md) "기존 서비스 조사"에 있습니다.

## 원칙

- 공고 자체보다 **실제로 지원할 주택**을 찾는 데 집중합니다.
- 지원 가능 여부와 살고 싶은지는 **따로** 판단합니다.
- 불확실한 내용을 임의로 확정하지 않고, **공식 원문을 확인할 수 있게** 둡니다.
- 생활 거점과 출퇴근 기준은 언제든 바꿀 수 있어야 합니다.
- 기능 수를 늘리기보다 **공고 확인에 드는 시간을 줄이는 것**을 우선합니다.

## 범위

1인용 개인 도구입니다. 로그인·권한·멀티유저를 만들지 않습니다. 현재는 배포하지 않고 로컬에서 실행합니다.

> 화면의 분류 결과는 **신청 자격 확정이 아닙니다.** 소득·자산·세대구성원 범위와 공고별 예외조건은 공식 공고문으로 최종 확인해야 하며, **최종 청약 신청은 사용자가 직접 수행합니다.** 인증수단을 보관하지 않습니다.
