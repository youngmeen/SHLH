# 집알림 — 서울 LH·SH 임대주택 공고 도우미

서초구·강남구·송파구의 공공임대 모집공고를 수집하고, 사용자가 입력한 조건에 따라 우선 확인할 공고를 정리하는 웹 MVP입니다.

## 현재 제공 기능

- 국토교통부 마이홈 API의 실제 LH 모집공고 수집
- SH 공식 주택임대 게시판 수집
- 나이·혼인·자녀·임신·한부모·주택 보유 조건 기반 1차 분류
- `조건 추천`과 `전체 공고` 분리
- 공급 규모, 접수일, 당첨자 발표일 표시
- LH·SH 공식 상세 페이지에서 신청자격·임대조건·일정 요약
- 공식 경쟁률이 확인된 경우만 표시
- 텔레그램 알림 화면 미리보기

> 추천 결과는 신청 자격 확정이 아닙니다. 소득·자산·세대구성원 범위와 공고별 예외조건은 공식 공고문으로 최종 확인해야 합니다.

## 빠른 실행

```bash
npm ci
cp .env.example .env.local
# .env.local에 발급받은 MOLIT_MYHOME_API_KEY 입력
npm run dev
```

기본 접속 주소는 터미널에 표시되는 `http://localhost:3000`입니다. 이미 사용 중이면 다음 포트가 자동 선택될 수 있습니다.

## 검증

```bash
npm run lint
npm test
```

`npm test`는 배포 빌드 후 공고 수집·조건 판정·상세 추출·서버 렌더링 테스트를 실행합니다.

| --- | --- |
| `npm run dev` | 로컬 개발 서버 실행 |

## 보안

- 실제 인증키는 `.env.local`에만 저장합니다.
- `.env.local`은 `.gitignore`에 포함되어 Git에 올라가지 않습니다.
- 문서, 이슈, 메신저, 화면 캡처에 인증키를 남기지 않습니다.
