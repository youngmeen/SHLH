# 공공데이터와 판정 범위

## 연결된 소스

### 국토교통부 마이홈 모집공고

- 안내: <https://www.data.go.kr/data/15108420/openapi.do>
- API: `https://apis.data.go.kr/1613000/HWSPR02/rsdtRcritNtcList`
- 현재 사용 필드: 공고 ID, 제목, 공급기관, 주택유형, 지역, 게시일, 접수기간, 공급호수, 당첨자 발표일, 주소, 원문 URL
- 인증: `MOLIT_MYHOME_API_KEY`

### SH 공식 주택임대 게시판

- 목록: <https://www.i-sh.co.kr/app/lay2/program/S1T294C297/www/brd/m_247/list.do>
- 모집공고 행을 읽어 제목, 담당부서, 게시일, 원문 URL을 구성합니다.
- 경쟁률·당첨자·서류심사 같은 후속 글은 모집공고 목록에서 제외합니다.

## 상세 공고 추출

선택한 공고의 공식 페이지에서 다음 제목 구간을 찾습니다.

- 공급정보
- 공급일정
- 임대조건
- 신청자격
- 제출서류
- 주의사항

HTML 본문에 없는 PDF·HWP 첨부 내용은 아직 자동 추출하지 않습니다.

## 조건 판정

현재 판정은 공고 제목과 사용자 프로필을 이용한 1차 관련도 판정입니다.

| 공고 신호 | 사용하는 입력 |
| --- | --- |
| 신혼·신생아 | 혼인 상태, 자녀 수, 임신, 한부모 여부 |
| 다자녀 | 자녀 수, 임신 여부 |
| 청년 | 나이, 혼인 상태 |
| 한부모 | 한부모 여부 |
| 고령자 | 나이 |
| 공통 | 주택 보유 여부 |

`조건 관련`은 신청 가능 확정이 아닙니다. 소득·자산·자동차·복지자격·세대구성원 범위는 공고별 기준을 구조화한 뒤 추가해야 합니다.

## 경쟁률

- 공식 상세 페이지에 `경쟁률 숫자 : 1` 형태가 있을 때만 표시합니다.
- 접수 중인 공고는 `아직 집계 전`으로 표시합니다.
- 현재는 별도 후속 경쟁률 공고와 원래 모집공고를 자동 연결하지 않습니다.
- 추정 경쟁률이나 신청건수 기반 임의 계산은 사용하지 않습니다.

## 지도 기능을 위한 데이터

공고 유형에 따라 위치 표현이 다릅니다.

| 유형 | 지도 표현 |
| --- | --- |
| 행복주택·국민임대·영구임대·장기전세 | 단지 주소 핀 |
| 매입임대·미리내집 | 첨부 주택목록에서 주소 추출 후 건물 핀 |
| 전세임대 | 선정자가 주택을 물색하므로 공급 가능 지역 영역 |

고정 단지는 별도 마이홈 단지정보 API를 연결할 수 있습니다.

- 안내: <https://www.data.go.kr/data/15110581/openapi.do>
- 모집공고 API와 별도 활용신청이 필요할 수 있습니다.
- 주소를 좌표로 바꾸는 지오코딩 공급자와 지도 라이브러리 선택이 필요합니다.
