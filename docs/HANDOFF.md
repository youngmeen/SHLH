# 작업 인수인계

## 목표

서울 서초구·강남구·송파구의 LH·SH 공공임대 공고를 모으고, 사용자 조건에 맞는 공고와 신청에 필요한 핵심 내용을 한 화면에서 보여주는 서비스입니다.

## 현재 상태

- 기준일: 2026-08-19
- 상태: 실데이터 로컬 MVP 동작
- 마이홈 모집공고 API 인증키: 로컬 `.env.local`에 설정됨
- Git 원격 저장소: 아직 연결되지 않음
- 로컬 데이터베이스: 사용하지 않음
- Telegram 실제 전송: 아직 연결하지 않음
- 지도: 설계 범위만 정리했으며 아직 구현하지 않음

## 검증 근거

- `npm run lint` 통과
- `npm test` 통과
- 전체 테스트 12개 통과
- 실제 LH 상세 페이지에서 신청자격·임대조건·공급일정 추출 확인
- 현재 공식 경쟁률이 없는 공고는 `아직 집계 전`으로 표시

## 바로 볼 파일

1. `app/page.tsx` — 전체 화면과 상태 흐름
2. `app/lib/notice-sources.ts` — 실제 공고 수집
3. `app/lib/audience-match.ts` — 조건 관련도 판정
4. `app/lib/notice-detail.ts` — 상세 공고 추출
5. `docs/ROADMAP.md` — 다음 구현 순서

## 다음 작업

지도 MVP부터 진행합니다.

1. 마이홈 공공임대주택 단지정보 API를 활용신청합니다.
2. 실제 응답의 주소·단지 ID·좌표 필드를 확인합니다.
3. 주소가 있는 공고와 구 단위만 가능한 전세임대를 구분하는 타입을 만듭니다.
4. 서초·강남·송파 지도와 목록을 연결합니다.
5. 데스크톱·모바일 상태와 빈 지도 상태를 테스트합니다.

지도 작업의 중단 조건은 `공식 데이터에 주소도 단지 식별자도 없는 경우`입니다. 이 경우 가상 좌표를 만들지 말고 구 단위 영역으로 표시합니다.

## 열린 질문

- 지도는 키 없는 OpenStreetMap으로 시작할지, 국내 주소 정확도가 높은 카카오·네이버·VWorld를 사용할지
- SH PDF/Excel 첨부파일을 서버에서 자동 수집해도 되는 운영 정책인지
- 사용자 프로필을 브라우저에만 둘지 데이터베이스에 저장할지
- 추천 결과를 알림에 포함할 때 어느 수준까지 자격 판정으로 표현할지

## 하지 말아야 할 것

- `.env.local`이나 인증키를 Git에 추가하지 않습니다.
- 전세임대 공고에 실제 공급주택이 있는 것처럼 가상 핀을 만들지 않습니다.
- 신청건수를 공식 최종 경쟁률로 표현하지 않습니다.
- 공고 제목만으로 신청 가능을 확정하지 않습니다.
- LH·SH 이외의 임의 URL을 상세 추출 API에 허용하지 않습니다.
- 사용자 확인 없이 실제 청약을 자동 제출하지 않습니다.
